# MASA³ — 端到端抗菌 Binder 设计平台（形态 A：AI 设计管线）

> 定位：输入病原菌种类 → 自动分析抗菌靶点 → 结构预测 → RFdiffusion 从头设计 binder → ProteinMPNN/ESM 评分 → 输出可靠序列。
> Killer application：金黄色葡萄球菌（S. aureus）→ 抗菌 binder → 湿实验验证（SPR Kd / MIC / 动物模型）→ 解决耐药性。
>
> **⚠️ 本文档描述的是早期「五环」形态，已升级为「十环」纳米注射器设计平台（HOUYI），见 `reports/HOUYI_模型报告V3-4.html`。环编号映射见文末「历史版本映射」。**

## 1. 完整管线（5 环）

```
输入：病原菌种类（如 "Staphylococcus aureus"）
  │
  ▼
【环 0】抗菌靶点分析  ← 本次新增的关键平台化升级
  │  从"细菌种类"自动推导该打哪些靶点
  │  知识库：毒力因子 / 耐药机制 / 表面暴露蛋白 / 保守性 / 免疫原性
  │  输出：靶点蛋白列表 + 序列（含机制分类）
  ▼
【环 1】结构预测
  │  靶点蛋白序列 → 3D 结构（AF2 / ESMFold / Chai-1）
  │  输出：靶点结构 (PDB)
  ▼
【环 2】RFdiffusion 从头设计 binder
  │  靶点结构 → 在表面"长出"binder 骨架
  │  输出：binder 骨架 (PDB)
  ▼
【环 3】ProteinMPNN / ESM 评分
  │  骨架 → 序列设计 + 折叠合理性/结合评分
  │  输出：binder 序列 + 评分
  ▼
【环 4】输出可靠 binder 序列（供合成/湿实验）
```

## 4. 环 0 靶点自动分析的设计思路

从"细菌种类"自动推导靶点，两条路线：

### 路线 A：规则/知识库驱动（先做，快）
- 维护一个"细菌 → 已知毒力因子/耐药靶点"知识库（金葡菌已有 15 靶标，扩展到其他菌种时逐步添加）
- 用 Uniprot/VFDB（毒力因子数据库）/CARD（耐药基因库）等公开库自动补充
- 输出：靶点列表 + 机制分类 + 序列（自动 fetch）

### 路线 B：模型驱动（后做，泛化）
- 训练/调用模型：输入细菌基因组/蛋白组 → 预测表面暴露+免疫原性+保守性的候选抗原
- 工具：SignalP（分泌信号肽）、TMHMM（跨膜域）、NetMHC（免疫原性）、保守性分析
- 这才是真正的"任意细菌→靶点"泛化能力

**建议**：路线 A 先落地（金葡菌跑通全链路），路线 B 作为"泛化到所有细菌"的二期能力。
