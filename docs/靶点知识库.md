# 金黄色葡萄球菌抗菌靶点知识库

> 这是 MASA³ 平台【环 0：抗菌靶点分析】的核心知识资产。
> 每个靶点都回答一个问题：**为什么它是值得打的靶点**（保守性/必需性/表面暴露/耐药相关性/临床验证）。

## 靶点筛选五原则
1. **表面暴露性** — 能被 binder 触及
2. **毒力/耐药相关性** — 打击病原体关键功能
3. **保守性** — 降低逃逸突变风险
4. **与宿主无同源性** — 降低脱靶毒性
5. **临床/疫苗已验证的免疫原性** — 降低翻译风险

## 重点靶点的科学论证（论文 Table 1 素材）

### 🔴 PBP2a（mecA）— MRSA 耐药的决定因子
- **机制**：替代内源 PBP 的转肽酶，对 β-内酰胺低亲和力 → 使 MRSA 在 β-内酰胺下仍能交联肽聚糖
- **为什么是好靶点**：MRSA 耐药的**唯一决定因子**（CARD 数据库 ARO:3000617），金葡菌基因组 45-70% 携带
- **临床证据**：抗 PBP2a 被动免疫 + β-内酰胺联合方案已被提出，可恢复廉价 β-内酰胺对 MRSA 的疗效
- **设计策略**：靶向变构位点（距活性位点 60Å），恢复 β-内酰胺敏感性

### 🔴 Hla（α-溶血素）— 最关键的毒力因子
- **机制**：成孔毒素，结合 ADAM10 形成七聚体孔道，溶解宿主细胞
- **为什么是好靶点**：95% 金葡菌分泌；hla 缺失株在肺炎/皮肤感染模型致病力显著下降
- **临床证据**：MEDI4893(Phase2)、AR-301(Phase3)、ASN100(Phase1) 多个抗 Hla 单抗进临床 — **证明 Hla 可成药**
- **设计策略**：阻断成孔前体 stem 域，阻止七聚体组装

### 🔴 ClfA — 已验证的粘附素靶点
- **机制**：结合纤维蛋白原，介导内皮定植（心内膜炎/导管感染关键）
- **为什么是好靶点**：clfA 高度保守，感染早期定植关键
- **临床证据**：tefibazumab(Aurexis) 进临床；Pfizer SA4Ag 疫苗含 ClfA
- **设计策略**：阻断 N2-N3 亚域纤维蛋白原结合裂隙

### 🟡 IsdB — 铁饥饿策略靶点
- **机制**：主要血红蛋白受体，NEAT 域捕获血红素供铁，感染部位上调
- **为什么是好靶点**：感染铁限制环境下上调表达
- **临床证据**：V710 疫苗靶点（最受研究疫苗候选之一，验证免疫学相关性）
- **设计策略**：阻断 NEAT 域血红蛋白结合

### 🟡 Agr 系统（AIP/AgrA）— 毒力主开关
- **机制**：群体感应，控制 Hla/PVL/PSM 等大量毒力因子
- **为什么是好靶点**：毒力 master switch，抗毒力策略核心
- **临床证据**：savirin 靶向 AgrA；AIP 类似物纳摩尔级抑制
- **设计策略**：AIP 捕获器 / 阻断 AgrA DNA 结合
